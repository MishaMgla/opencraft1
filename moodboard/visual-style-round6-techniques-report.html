Same horse, same grass — five rendering languages

Rounds 1–5 varied the world's material, which locked every asset into one hue. This round varies the pixel-art technique itself — the layer that separates a modern indie game from a 16-bit cartridge or a dithered DOS title. Subject colors stay free and natural in all five (brown horse, green grass); what changes is outline policy, shading model, dithering, pixel density, and color-count philosophy. Every sample was generated locally with the prompt + outline parameter shown on its sheet, stored in web/assets/manifest.json.

TECHNIQUE 1 / 5

Retro Console

A cartridge game from the arcade era. Thick black outlines, three-shade cel ramps, saturated color. Any hue is welcome — the discipline is in the ramp count, not the palette.

Technique rules

  • Outline: thick single-color black on everything.
  • Shading: exactly three steps per material — base, shadow, highlight; hard cel edges.
  • Color: saturated and punchy, free hue; few colors per material, many across the world.
  • Density: chunky — sprites read like 32px art shown at 2×.
  • Avoid: anti-aliasing, gradients, dithering, atmospheric tinting.

Saved prompt + parameters

horse · chunky retro arcade pixel horse with brown coat, red saddle, three-shade cel colors and thick pixels tile · chunky retro arcade green grass tile with three-shade cel colors and thick pixels param · --outline "single color black outline"

Result reads instantly game-like and friendly; the tile self-subdivides into a 3×3 block grid, which tiles busily at world scale.

TECHNIQUE 2 / 5

Hi-Bit Painterly

Modern indie pixel art. No outlines, soft ramps, shadows that shift hue toward cool instead of just darkening. Atmosphere over punch.

in-game composite
horse · 64px
grass · 64px

Technique rules

  • Outline: none — forms separate by value and temperature.
  • Shading: soft multi-step ramps; every shadow shifts hue (green grass shades toward blue, brown coat toward violet).
  • Color: extended count, muted-to-rich, free hue; light tells the story.
  • Density: full 64px detail, hand-placed pixel clusters.
  • Avoid: black outlines, flat cel steps, saturation spikes.

Saved prompt + parameters

horse · modern hi-bit painterly pixel horse with brown coat, soft hue-shifted shading and a teal saddle blanket tile · modern hi-bit painterly green grass tile with soft hue-shifted shading and scattered leaf detail param · --outline "lineless"

The most contemporary-feeling pair; the tile's soft luminous gradient would give the world gentle depth, but silhouettes are the least crisp of the five.

TECHNIQUE 3 / 5

Poster Flat

A silkscreen poster that happens to be pixels. Solid fills, two values per material, geometry-first silhouettes, zero texture.

in-game composite
horse · 64px

Technique rules

  • Outline: none — shape does everything.
  • Shading: at most two values per material; no ramps at all.
  • Color: bold, confident, free hue; large uninterrupted fields.
  • Density: effective detail is low by choice — silhouette-scale drawing.
  • Avoid: texture noise, dithering, gradients, tiny detail clusters.

Saved prompt + parameters

horse · flat poster style horse in solid fills with brown coat, mustard saddle, two values per color and a strong geometric silhouette tile · flat poster style green grass tile in solid fills with simple geometric blade shapes param · --outline "lineless"

The most ownable and scalable of the five — the horse is pure silhouette and the pebble-flat tile stays calm when repeated. Strongest small-scale readability.

TECHNIQUE 4 / 5

Ordered Dither

A workstation game from the DOS/PC-98 era. Every gradient is an honest, visible dither pattern; color stays muted and earthy.

in-game composite

Technique rules

  • Outline: selective — thin dark line only where forms would merge.
  • Shading: gradients exist only as ordered dither patterns; no smooth ramps.
  • Color: muted, low saturation, free hue; the dither carries richness.
  • Density: fine — dither needs full 64px resolution to breathe.
  • Avoid: smooth ramps, saturation spikes, random-noise dithering.

Saved prompt + parameters

horse · retro PC pixel horse with visible ordered dithering, muted earthy brown tones and a leather saddle tile · retro PC green grass tile with visible ordered dithering and muted earthy tones param · --outline "selective outline"

The horse is handsome and serious; this tile generation picked up glyph-like artifacts in two cells and would need a re-roll before judging the terrain fairly.

TECHNIQUE 5 / 5

Toy Render

Pre-rendered miniatures. Rounded volumes, smooth shading with a gentle plastic gloss — the world as a tabletop of solid little toys.

in-game composite
horse · 64px

Technique rules

  • Outline: none — volume shading defines edges.
  • Shading: smooth rounded gradients with one soft specular per form.
  • Color: clean plastic tints, free hue; solid and opaque, never gritty.
  • Density: forms simplified into rounded masses; detail is molded, not drawn.
  • Avoid: visible pixel-cluster technique, texture grain, hard cel steps.

Saved prompt + parameters

horse · pre-rendered toy style pixel horse with rounded volumes, smooth shading, glossy plastic look and a blue saddle tile · pre-rendered toy style green grass tile with rounded plastic turf clumps and smooth shading param · --outline "lineless"

Charming and cohesive as a pair; the 3×3 turf-clump tile repeats visibly, so a shipped version would want 2–3 tile variants to break the grid.

To pick a direction: name the technique. Its prompt phrasing + outline parameter become the standing suffix for every future asset, with subject hue free per asset — so grass is green, lava is red, and the world still reads as one game.

Note on rounds: a material world (round 5) and a technique (round 6) compose — e.g. "Poster Flat rendering of the Brass Orrery world" is a valid final identity. Techniques answer how it's drawn; materials answer what the world is made of.
