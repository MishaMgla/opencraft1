This round explores five untouched materials — leaded glass, chalk on slate, molded beeswax, sawn lake ice, machined brass — each as a full pair: an isometric horse and its grass tile, composited below exactly as they would sit in game. Every sample was generated from the prompt lines shown on its sheet; the same lines are stored in docs/specs/…issue-130… and web/assets/manifest.json, so the winning style's language is reusable as-is.

Glazier Vault

A world assembled from leaded lantern glass. Every surface is a glazed panel set in dark came, lit gently from within — the black joint lines carry all the drawing.

Rules

  • Light: backlit glow — fills brighten at center, came lines own every edge; one hard ground diamond per object.
  • Texture: streaky rolled glass, bubble specks, soldered joints — at most one streak per pane.
  • Readability: the horse is 6–10 big glass facets; the black came outline guarantees the silhouette at tile scale.
  • Avoid: church iconography, prism gradients, bloom, photoreal refraction.

Chalk Meridian

Rules

  • Light: none — value comes from chalk density; a shadow is a hatched patch, never a gradient.
  • Texture: dry chalk grain, erasure ghosts, slate speckle; exactly one hatch pattern everywhere.
  • Readability: solid chalk-filled silhouette with 2–3 slate cut lines for saddle and neck — never line-art only.
  • Avoid: schoolroom kitsch, sketch noise, neon chalk, blueprint blue.

Rules

Rules

  • Light: single cool studio key; exactly one 1–2px brass glint per object, never bloom; flat midnight shadows.
  • Texture: engraved ticks, brushed bands, enamel-filled stamps — engraving only where it explains function.
  • Readability: brass automaton animal; cream chart saddle plate for contrast, solid head silhouette, no gears breaking it.
  • Avoid: steampunk gear clutter, holograms, literal clock faces, zodiac dumping.
