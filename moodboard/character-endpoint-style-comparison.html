Character-endpoint style comparison

The same four characters generated through PixelLab's multi-direction character endpoint — the one real production will use — in seven styles. Shown here at the south-east facing on the neutral game ground, matched size.

Read this first: the character endpoint imposes its own clean sprite look and only weakly honors render-technique words, so the styles differ subtly (palette, shading softness, outline weight, contrast) rather than dramatically. This is the true, honest preview of production characters — unlike the earlier flat hud samples, which showed a stronger style the rotating pipeline can't reproduce. Whatever you pick here, the world (tiles/props) still gets the full-strength style from the flat endpoint.
