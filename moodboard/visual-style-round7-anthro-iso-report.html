Ten techniques, one horse-person, one floor

Round 7 renders the anthropomorphic horse character (horse head, standing on two legs) and a seamless isometric grass tile in ten rendering techniques — the five from round 6 plus five new ones. The engine-view panel shows the floor exactly as the game draws it: the square texture squashed 2:1 into stitched diamonds (drawTexturedPaintTile). The seam strip repeats the raw tile flat; the score is the mean edge mismatch (<25 reads stitch-free — the currently shipped grass-tile scores 66). All prompts are stored in web/assets/manifest.json.

TECHNIQUE 1 / 10

Retro Console

A cartridge game from the arcade era. Thick black outlines, three-shade cel ramps, saturated color — hue free, ramp count fixed.

Technique rules

  • Outline: thick single-color black on everything.
  • Shading: exactly three steps per material, hard cel edges.
  • Color: saturated and punchy, free hue.
  • Avoid: anti-aliasing, gradients, dithering.

Best all-round pair: the chibi horse-person's black outline pops against the dense cel grass, and the tile is seam-perfect (0.7).

Technique rules

  • Shading: soft multi-step ramps, shadows shift hue toward cool.
  • Color: extended count, muted-to-rich, free hue.

To pick a direction: name the technique. Its prompt phrasing + parameters become the standing suffix for all future assets. For the winning style, the player character should be regenerated once more via PixelLab's character endpoint with the humanoid mannequin template — that endpoint guarantees the bipedal pose and produces the four ISO facings the renderer needs, which the single-image endpoint only approximates.
